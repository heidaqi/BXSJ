# 实时链路测试报告

## 自动化测试

运行命令：`.venv\Scripts\python.exe -m unittest discover -s backend\tests -v`

本轮共18项，实际结果全部通过，覆盖：

- COMSOL目录读取与统一FMC结构。
- 已知点反射体DAS定位、YOLO物理坐标换算。
- 波形降采样、初始闸门、底波闸门和通道越界。
- DAS点位双程声程与Tx-Rx到达样本反查。
- 1000次稳定源轮询不重复生成帧。
- 原始文件读取期间变化时丢弃该快照。
- JSON原子替换失败时保留上一份完整记录。
- 磁盘剩余不足512 MB时在读取/成像前停止。
- YOLO队列固定上限10、Agent队列满时记录失败并返回错误。
- 外部Agent无结果时继续A扫与DAS主导分析。
- 实时批次PDF实际生成并验证PDF文件头。

前端执行 `npm run build`，Vite生产构建通过。

## 尚未替代的现场测试

当前持续运行测试是快速、确定性的1000次轮询测试，不等同于真实设备小时级压力测试。协议与帧率明确后仍需执行：

- 连续8至24小时采集，记录内存、CPU、磁盘增长和帧延迟分位数。
- 按实际设备写入顺序模拟通道迟到、丢包、重复帧和断线恢复。
- 在接近真实帧率下压满YOLO与Agent队列，确认选定的背压或丢帧策略。
- 使用受控磁盘配额验证报告、NPZ和图像同时写入时的恢复行为。
- 断电或强制结束进程后检查 `.tmp` 文件清理与批次“已中断”恢复。
