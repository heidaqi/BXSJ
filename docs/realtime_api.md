# 实时处理接口

接口前缀：`/api/realtime`

## 会话与数据源

- `POST /config`：配置并校验数据源和成像参数。
- `POST /start`：启动当前会话的数据处理。
- `POST /stop`：停止接收新数据并完成当前会话归档。
- `GET /status`：获取连接、校验、处理进度和最近错误。
- `WS /ws`：订阅状态与帧更新。

## 帧

- `GET /frames/latest`：读取当前会话最近完成帧。
- `GET /frames/{frame_id}`：读取指定帧的统一记录。
- `GET /frames`：分页读取当前会话帧列表。

帧结果以校验后的 MATLAB 输出为准，并包含数据来源、扫查时间、图像、检测结果、质量状态、标定和复核信息。前端展示与后续报告使用相同记录版本。

## 批次与报告

- `POST /batches`：冻结当前会话的已完成帧并创建分析批次。
- `GET /batches`：读取批次列表。
- `GET /batches/{batch_id}`：读取批次详情及分析状态。
- `POST /batches/{batch_id}/retry`：重试失败或中断的分析。
- 报告接口由用户主动调用，并接受目标保存路径。

处理失败不会删除已经落盘的原始引用、成像结果和校验记录。新数据源会创建新会话，历史批次不会混入当前批次。

## 错误约定

- `400`：请求参数或数据格式错误。
- `404`：帧或批次不存在。
- `409`：会话状态冲突或证据不完整。
- `429`：后台任务队列达到上限。
- `507`：文件或报告写入失败。
