# 实时监控操作说明

1. 在“实时监控”中选择单个 FMC 数据组或包含多组数据的父目录。
2. 点击“校验数据源”，查看有效组和跳过原因。没有有效组时不能开始处理。
3. 核对采样率、模拟扫查间隔、车速等本次参数。默认采样率为 50 MHz。
4. 点击“开始处理”。MATLAB 首次启动时间较长，后续数据组复用同一会话。
5. 主画面会异步显示最近完成的成像与校验后检测结果；暂停显示不会暂停后台计算。
6. 数据处理结束后点击“停止处理”。系统完成当前组、写入帧记录并归档会话。
7. 在“批次复盘”中查看各帧图像和结果，按需确认、标记误检或人工补录。
8. 在“Agent 与报告”页面运行辅助分析，并选择 PDF 保存位置。

## 记录规则

每组数据在完整接收时记录扫查时间，并使用唯一 `frame_id` 关联原始数据、成像图、校验后检测结果和人工操作。模拟车速与时间可估算扫查路径位置，但不作为缺陷截面坐标的替代依据。

复核和坐标标定保存后会更新当前批次统一记录。再次运行 Agent 或生成报告时读取最新记录，不读取历史缓存中的旧结果。

## 异常处理

- 校验失败：根据页面列出的通道、列数、时间轴或阵元配置问题修正数据。
- MATLAB 不可用：在应用设置中检查 MATLAB 路径和环境自检结果。
- 处理停止：可重新选择数据源创建新会话；旧会话保留为历史记录。
- Agent 不可用：检查 API 地址、模型名、API Key 和网络。本地确定性结论仍可查看。
- 质量门控未通过：报告不会把该批次写成“未检出需记录异常”，应补充检测或复核。
