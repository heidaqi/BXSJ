# PAUT 数据流成像操作说明

当前页面用于处理团队确认的 16发16收 COMSOL 仿真数据。硬件尚未到位时，系统把本地目录当作设备数据源；参数来自 `DAS.m`，非16发16收数据暂时不进入本阶段验收。

1. 进入“PAUT 数据流成像”，填写包含16发16收数据组的父目录，例如 `D:\PAUTData\batch_001`。
2. 点击“校验数据源”。确认通道维度和阵元配置提示无误后点击“开始处理”。
3. 后端逐组执行A扫读取、DAS成像、A扫特征提取和YOLO检测；前端异步显示最新已完成图像，显示暂停不会阻塞后端。
4. 日常监控不显示通道波形。需要核查疑似位置时，在DAS图标题栏开启“高级复核”；系统会锁定当前显示画面，但后台仍继续采集和分析。
5. 点击锁定图中的关注位置后，高级复核会显示相关Tx-Rx通道及首选通道A扫波形。点击通道列表可切换波形，黄色区域提示初始脉冲排除区和预计底波闸门；关闭高级复核后清除当前选点和波形，并按进入前的状态决定是否恢复自动跟随。
6. 数据处理期间不运行Agent。单组覆盖目录无变化时会显示“等待设备写入”；多组父目录会显示已处理组数和总组数。
7. 停止处理并等待图像检测队列清空后，点击“分析本次采集”。系统冻结本次会话的全部A扫、DAS图、YOLO结果和真值解析结果进行联合分析；YOLO没有候选框时仍分析A扫和DAS证据。
8. 人工确认、误检处理和报告归档在采集后按批次统一完成。

每组数据会保存为独立证据包：原始A扫、DAS矩阵、DAS图、YOLO结果、A扫特征、profile参数和真值解析结果放在同一个 `frame_id` 目录中。文件夹名中 `(0.035,0.025)-(0.045,0.02)` 表示裂纹线段，`d5mm(0.05,0.02)` 表示圆形气孔。单帧A扫不能判断缺陷长度、走向/倾角、缺陷类型和真实尺寸，Agent只在采集后综合全部数据组进行辅助推理。

批量验证可运行：

```powershell
.\.venv\Scripts\python.exe .\scripts\validate_paut.py --data-root "D:\PAUTData\batch_001"
```

当前没有MATLAB `.mat` 输出文件时，报告只说明Python按新版 `DAS.m` 逻辑复现后的结果与文件名真值之间的关系，不声明与MATLAB数值矩阵完全一致。

出现“文件在读取过程中发生变化”时，说明设备或模拟程序尚未完成通道写入，系统会丢弃本轮并自动重试。出现磁盘不足时应停止监听并清理或迁移历史输出，不应绕过容量保护。
