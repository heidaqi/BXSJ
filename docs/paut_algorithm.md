# PAUT 成像与波形算法说明

## 当前验证对象

当前阶段只验收团队确认的 16发16收 COMSOL 仿真数据。参数来自 `DAS.m`：阵元位置为 `[30,32,34,36,38,40,42,44,49,51,53,55,57,59,61,63] mm`，发射和接收相同；钢中纵波声速 `5900 m/s`，板厚 `40 mm`，采样间隔 `2e-8 s`，成像区域为 `x=20-70 mm`、`z=0-40 mm`，包络后默认使用 `sigma=0.4 mm` 二维高斯平滑。8发8收、14发16收等数据暂不作为当前实时模块验收对象。

## 仿真真值解析

数据文件夹名提供当前阶段的真值：`(x1,z1)-(x2,z2)` 表示由两点连线构成的裂纹线段，目录中坐标单位为 m，程序换算为 mm；`d5mm(x,z)` 表示中心为 `(x,z)`、直径为5 mm的圆形气孔，坐标单位同样从 m 换算为 mm。其他格式只在能够明确解析时进入 `truth.json`，含义不明确时标记为待确认。

## 能力边界

A扫单帧不能可靠判断缺陷长度、走向/倾角、缺陷类型和真实尺寸。当前程序的物理证据包括DAS聚焦位置、相关通道回波、门控包络、主频、底波覆盖和YOLO候选区域；缺陷类型、长度和走向只能在整批多帧数据中结合仿真真值、工艺先验和人工复核综合分析。

## 仿真验证指标

在无MATLAB `.mat` 输出文件时，系统执行“Python对新版DAS.m逻辑复现 + 文件名真值距离验证”。每组数据同时记录：

- 全局内部最强峰：用于发现主要强反射，但不直接等同于缺陷位置。
- 目标邻域响应：在仿真真值附近搜索局部最强响应，用于判断目标区域是否存在可见DAS响应。
- 距离指标：裂纹计算点到线段距离，气孔计算点到圆形区域/圆心距离。
- 风险提示：采样窗、初始脉冲、板厚底波覆盖和目标含义待确认等。

## 统一数据

内部A扫帧固定为 `[tx, rx, sample]`。当前COMSOL目录适配器读取 `tx_N/通道.txt`，时间轴必须等间隔。设备协议确定后应新增适配器，不修改DAS与分析服务。

每个实时帧冻结保存：

- `raw/raw_frame.npz`：A扫、时间轴、Tx/Rx坐标。
- `das/das_data.npz`：线性DAS、dB图和x-z坐标轴。
- `analysis/truth.json`：由文件夹名解析的仿真真值。
- `analysis/profile.json`：当前成像profile和DAS.m参数。
- `frame.json`：参数、耗时、分析、复核与文件引用。
- `das/das.png`、`yolo/das_annotated.jpg`：显示和YOLO输入。

## DAS

成像点 `(x,z)` 对通道 `(tx,rx)` 的到达时间为：

`t = (sqrt((x-tx_x)^2+z^2) + sqrt((x-rx_x)^2+z^2)) / c`

按采样间隔换算为最近样本后跨通道叠加，再沿深度方向计算解析包络；新版 `DAS.m` 在包络后、转dB前执行二维高斯平滑，当前Python实现使用相同的默认 `sigma=0.4 mm` 和边缘复制策略。阵元坐标、声速、零时刻误差和平滑参数会影响图像外观与峰值位置。

## A扫与闸门

波形接口返回原始波形和Hilbert解析包络。为控制传输量，显示数据等距降采样，闸门和DAS反查始终使用全采样数据。

- 初始脉冲排除区：默认排除约3 mm单程深度对应的6 mm往返声程。
- 预计底波闸门：以 `2 * 板厚 / 声速` 为中心，当前显示范围为预计时间的96%至104%。
- 闸门用于复核提示，不是验收阈值。增益、耦合、楔块延迟和仪器零点确定后还需重新标定。

## DAS点击反查

前端点击位置先由DAS图像比例换算为x-z毫米坐标。后端为全部Tx-Rx计算该点的双程到达样本，读取对应包络幅值并排序，返回前1至32个通道。该排序说明“哪些通道在该聚焦时刻贡献较强”，不等同于缺陷类型判断。
