# PAUT 算法与结果边界

## 主链路

系统将合法 FMC 数据交给团队 MATLAB 算法，依次完成数据读取、DAS 成像、缺陷检测、定位、二维定量和结果保存。Python 后端只负责数据校验、调用、结果结构化、质量门控和业务归档，不修改 MATLAB 检测数值。

## 权威结果

`Paut.m` 及其调用的算法输出是缺陷类别、中心位置、峰值位置、长度、直径、面积、截面方向和信噪比的唯一算法来源。后端适配器会检查字段类型、有限数值、单位和质量状态，再生成统一结果包。

预校验候选只用于算法结果缺失时定位故障，不进入正常 Agent 结论和正式报告。缺少的定量字段保持为空，不以经验值或大模型内容补齐。

## 坐标与尺寸

结果中的 `x` 和 `z` 为当前成像截面的物理坐标。阵元位置、声速、采样率、板厚和成像网格会影响定位及定量，因此必须来自已校验配置。图片标定只用于显示和人工补录，不覆盖算法已经给出的物理坐标。

长度、直径、面积和方向均表示当前 `x-z` 截面的二维估计，不表示缺陷三维真实尺寸或空间走向。

## Agent 边界

Agent 消费统一结果包，并结合人工复核、数据质量和权威知识库生成风险说明。它不得更改算法数值或把不完整证据表述为确定结论。最终验收仍需依据适用产品标准、检测工艺和有资质人员判断。
