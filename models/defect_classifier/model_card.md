# 模型卡 (Model Card) — PAUT/FMC 缺陷四分类

## 当前项目默认模型

| 项 | 内容 |
|---|---|
| 模型名 | PHYS_ROBUST_EXTRA_TREES |
| 模型版本 | phys_robust_v1 |
| 文件 | `models/defect_classifier/best_PHYS_ROBUST.joblib` |
| 用途 | 单帧 A扫/FMC 主要响应四分类辅助判断 |

本项目运行时默认使用 `best_PHYS_ROBUST.joblib`。模型输入不是原始图片，而是由完整单帧 A扫/FMC 数据提取出的 17 维物理特征，用于给出夹渣、裂纹、气孔、未熔合四类主要响应概率。运行时每帧只分类一次，不把同一预测复制为多个候选点的独立类别。

运行时会做两点保护：

- 对项目传入声速与 `6200 m/s` 做内部概率融合，降低声速参数差异造成的硬误判。
- 最高类别概率低于 `0.70` 时输出“不确定”，不强行定型。

模型结论只作为 Agent、报告和人工复核的辅助依据，不替代检测人员定性或标准验收结论。

---

## 输入输出

| 项 | 内容 |
|---|---|
| `fmc` | (16, 16, n_t) float, 顺序 (发射阵元, 接收阵元, 时间), 单位 Pa(尺度任意) |
| `t` | (n_t,) float, **秒**, 需与 fmc 时间维等长 (训练 dt=20 ns) |
| `x_el` | (16,) float, 阵元 x 坐标, **mm** |
| `candidate_x_mm` / `candidate_z_mm` | 可选, 帧内主能量响应锚点 (mm, 深度自顶面); 缺省自动 TFM 定位 |
| 输出 | 当前帧主要响应的类别、中文类别、置信度、四类概率、复核建议 |

## 特征说明

模型使用 17 维纯物理特征，不直接使用深度、长度、倾角等标签信息：

- 散射矩阵熵 ×2 (各向同性度)
- 镜面脊线: 斜率/截距/拟合优度/锐度/偏离占比
- 背向散射占比、近法向入射占比
- 回波谱: 质心/带宽/低高频比
- 回波包络: FWHM 时长/偏度
- TFM 亮斑: 长宽比/主轴方向/对比度

## 已知局限

1. **样本仅 43 个**, 且来自三套不同的 COMSOL 配置(幅值/阵列几何/时间窗
   不一致); 100% 的 LOO 结论需在统一配置重跑的数据上复核后方可作为
   最终工业验收依据。
2. 裂纹/气孔子集为分裂孔径阵列, 其余为连续孔径; 特征虽按逐 case 归一
   设计, 仍可能残留少量几何信息。
3. 多缺陷 case(2 裂纹 / 多气孔)仅取主缺陷中心提取特征。
4. 自动 TFM 定位偏差约 ±3 mm(对裂纹可能更大), 有候选位置时应传入
   候选位置。
5. 特征提取依赖帧内主能量锚点或 TFM 定位；该模型不负责拆分同帧多个物理缺陷。

## 适用边界

- **适用**: COMSOL/同类仿真的 16×16 PAUT FMC 数据, 5 MHz 量级中心频率,
  dt=20 ns, 钢板 40 mm, 单缺陷为主的夹渣/裂纹/气孔/未熔合四分类。
- **不适用 / 需谨慎**: 其他阵元数、其他板厚与材料、dt 偏离 20 ns 较大、
  多缺陷密集场景、真实工业噪声数据(未经验证)。

## 结论

本模型用于桌面检测系统的**辅助判别**。**不构成最终工业验收结论**;
工业验收需在统一配置、更大样本、真实试块数据上重新训练与认证。
