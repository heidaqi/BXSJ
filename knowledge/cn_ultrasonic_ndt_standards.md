# 中国超声检测与相控阵检测相关标准知识库

> 用途：供本系统 Agent 在生成复核建议、报告说明和风险提示时参考。本文只整理公开可核验的标准信息、适用场景和软件侧注意事项，不复制标准正文；正式验收、质量等级和判废结论应以现行有效标准原文、合同技术条件和持证人员判定为准。

## 一、标准体系定位

本系统同时处理检测图片，以及原始 A 扫/FMC 数据的适配、DAS 成像和同帧辅助分析。当前实时输入仍为仿真目录模拟，不直接控制相控阵设备。因此，标准知识库主要用于：

- 提醒操作者记录检测条件、标定方式、图像来源、复核状态和报告边界。
- 辅助 Agent 解释“模型检出/人工补录/误检/未标定”的风险。
- 约束报告措辞，避免把 AI 识别结果直接写成标准验收结论。
- 提醒用户：焊缝/承压设备/相控阵检测的验收等级和质量分级必须回到相应标准原文。

原始数据实时模式还必须遵守以下边界：

- A扫数据、DAS图像、校验后检测结果和Agent结果必须使用同一个 `frame_id` 关联。
- 自发自收通道可按脉冲回波声程估算表观深度；FMC其他通道必须使用发射点到像素再到接收点的总声程。
- 仿真数据可用于算法位置验证，不能替代真实设备、试块和工艺验证。
- Agent只能辅助解释波形与成像证据，不能仅凭波形峰值自动确定裂纹、气孔、夹渣等缺陷类型。

## 二、重点标准索引

### 自动PAUT焊缝标准的优先关系

- GB/T 40733-2021《焊缝无损检测 超声检测 自动相控阵超声技术的应用》是焊缝自动PAUT的方法候选，不能用常规手工UT标准替代。
- GB/T 40734-2021《焊缝无损检测 相控阵超声检测 验收等级》是焊缝PAUT验收候选。公开范围信息指向厚度不小于6 mm的铁素体钢全熔透焊缝；缺少材料、接头形式、验收等级、灵敏度和指示评定数据时不能进行验收判定。
- GB/T 43320-2023与GB/T 44051-2024分别是3.2 mm至8.0 mm薄壁钢构件自动PAUT方法和验收候选。板厚处于该范围时，应优先判断薄壁标准适用性。
- NB/T 47013.15-2021只在检测对象明确属于承压设备时作为行业方法与分级候选，不应默认套用于普通焊缝。
- GB/T 32563-2016提供通用PAUT方法支撑；GB/T 41114-2021和GB/T 42399系列分别支撑试块校准和设备性能证据。
- GB/T 11345-2023公开范围主要为手工常规超声检测，自动PAUT任务中只能作为相关参考，不能替代GB/T 40733-2021。

### 1. GB/T 11345-2023 焊缝无损检测 超声检测 技术、检测等级和评定

- 状态：现行。
- 发布日期：2023-11-27。
- 实施日期：2024-06-01。
- 替代：GB/T 11345-2013。
- 公开信息定位：焊缝超声检测的方法、检测等级和评定。
- 软件侧启示：
  - 报告应记录检测对象、焊缝/区域、检测等级或工艺依据。
  - 仅凭图像 AI 框选不能替代标准要求的检测工艺、灵敏度设置、扫查覆盖和评定。
  - 对焊缝类图像，Agent 可提示“需结合检测等级、扫查覆盖、显示长度和回波/图像响应复核”。

### 2. GB/T 29712-2023 焊缝无损检测 超声检测 验收等级

- 状态：现行。
- 发布日期：2023-11-27。
- 实施日期：2024-06-01。
- 公开信息定位：焊缝超声检测验收等级。
- 软件侧启示：
  - 报告中不应只写“发现缺陷/无缺陷”，还应说明是否具备验收等级判断条件。
  - 若本系统只基于图片识别而没有完整 A 扫、检测等级、回波幅度、显示长度等信息，应写明“本报告仅为图像辅助识别结果，不直接给出 GB/T 29712 验收等级判定”。
  - Agent 不应编造合格/不合格阈值；应提示复核标准原文和项目技术条件。

### 3. GB/T 32563-2016 无损检测 超声检测 相控阵超声检测方法

- 状态：现行。
- 发布日期：2016-02-24。
- 实施日期：2016-10-01。
- 公开信息定位：相控阵超声检测方法。
- 公开范围信息显示：适用于一维线阵相控阵超声技术，包含手工、自动或半自动扫查的应用原则、工艺参数选用和缺陷定位/定尺寸方法；主要适用于一定厚度范围的细晶钢焊接接头，其他材料或范围需考虑声速、信噪比和验证演示。
- 软件侧启示：
  - PAUT 图像应保留探头、阵元、楔块、声速、扫查方式、编码器、灵敏度、聚焦法则等来源信息。
  - 如果当前系统只接收渲染后的 B 扫/S 扫图片，不能反推出完整相控阵工艺参数。
  - 缺陷物理坐标若只由图像比例尺得到，应标明“图片内坐标”，不能宣称为工件全局坐标。

### 4. NB/T 47013.3-2023 承压设备无损检测 第3部分：超声检测

- 状态：公开信息显示为 valid/现行，实施日期 2024-06-28。
- 替代：NB/T 47013.3-2015。
- 公开信息定位：承压设备超声检测方法和质量评级要求，面向 A 型脉冲反射法等超声检测场景。
- 软件侧启示：
  - 承压设备场景下，报告应关注检测时机、检测比例、检测面状态、试块、探头、耦合剂、仪器状态、扫查覆盖、记录和评定依据。
  - 对只上传图片的情况，应提示资料不足：无法核实检测面、设备校验、扫查覆盖、灵敏度设定等关键条件。

### 5. NB/T 47013.15-2021 承压设备无损检测 第15部分：相控阵超声检测

- 状态：现行。
- 发布日期：2021-04-26。
- 实施日期：2021-08-26。
- 公开信息定位：承压设备相控阵超声检测方法和质量分级要求；公开简介称其属于可记录脉冲反射超声检测。
- 软件侧启示：
  - 对 PAUT 图片，应区分“模型识别框”和“检测工艺记录”。
  - 若缺少原始 PAUT 数据、聚焦法则、校准记录、扫查路径和编码器信息，应提示不能独立完成标准意义上的相控阵检测评定。
  - 人工补录缺陷应保留来源字段，报告中不能写成设备自动判定。

### 6. GB/T 12604.1-2020 无损检测 术语 超声检测

- 状态：现行。
- 发布日期：2020-11-19。
- 实施日期：2021-06-01。
- 公开信息定位：超声检测术语基础；公开信息说明本部分不包括相控阵检测术语。
- 软件侧启示：
  - 报告术语应尽量使用“显示、反射、回波、缺陷、缺欠、扫查、灵敏度、校准、试块”等无损检测常用词。
  - 相控阵相关术语应额外参考阵列超声术语标准或 PAUT 方法标准。

### 7. GB/T 41114-2021 无损检测 超声检测 相控阵超声检测标准试块规范

- 状态：公开信息显示现行。
- 发布日期：2021-12-31。
- 实施日期：2022-07-01。
- 采用：ISO 19675:2017。
- 公开信息定位：相控阵检测标准试块规范。
- 软件侧启示：
  - 若报告中涉及相控阵检测能力、灵敏度或系统校准，应关注是否有试块、校准记录和标定说明。
  - 仅上传检测图片时，Agent 应提示“缺少试块/校准证明时，不能确认检测灵敏度满足工艺要求”。

### 8. 超声检测设备与相控阵设备性能相关标准

- GB/T 27664.1-2026：无损检测仪器 超声检测设备的性能与检验 第1部分：仪器。公开信息显示发布日期 2026-01-28，实施日期 2026-08-01，替代 GB/T 27664.1-2011。
- GB/T 27664.2-2026：无损检测仪器 超声检测设备的性能与检验 第2部分：探头。公开信息显示发布日期 2026-01-28，实施日期 2026-08-01。
- GB/T 27664.3-2026：无损检测仪器 超声检测设备的性能与检验 第3部分：组合设备。公开信息显示为相关标准。
- GB/T 42399.1-2023、GB/T 42399.2-2023、GB/T 42399.3-2023：公开信息显示为相控阵超声设备性能与检验相关标准。
- 软件侧启示：
  - 工业报告中建议保留设备型号、探头/通道、校准或性能核查信息。
  - 当前系统只处理图片时，应把设备性能和校准信息作为“外部输入/人工填写/元数据绑定”处理，不能由图像模型自动推断。

## 三、Agent 输出约束

Agent 在分析中国超声检测/相控阵检测图片时，应遵守：

- 不直接判定是否满足某标准验收等级，除非用户提供完整标准条款、检测工艺、检测等级、验收等级、原始检测数据和评定条件。
- 对模型 0 检出场景，应提示：小目标、低信噪比、图像缩放、训练集差异、阈值设置均可能造成漏检。
- 对人工补录，应明确写成“人工复核/补录结果”，不要伪装为模型自动检出。
- 对未标定图片，应只输出像素坐标，不输出物理坐标结论。
- 对只有图片没有元数据的场景，应提示缺少：设备型号、探头/通道、扫查区域、比例尺、检测工艺、校准/试块、检测等级、验收等级等。

## 四、可用于报告的规范化措辞

- “本系统基于上传图像进行缺陷辅助识别，识别结果需由具备资质的检测人员结合原始检测数据和适用标准进行复核。”
- “未提供比例尺或标定信息的图片，仅输出图片内像素坐标，不进行物理尺寸推断。”
- “人工补录缺陷已在缺陷来源字段中标识，报告统计时应与模型检出结果区分。”
- “若用于焊缝或承压设备验收，应结合 GB/T 11345、GB/T 29712、NB/T 47013 等适用标准和项目技术条件进行最终评定。”
