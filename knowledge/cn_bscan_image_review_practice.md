# 超声 B 扫/相控阵图像辅助识别实践知识

> 用途：供 Agent 在分析上传的 B 扫、S 扫、TFM 或相控阵成像截图时参考。本文面向软件工作流，不替代检测工艺规程和标准原文。

## 一、当前系统的数据边界

当前系统接收的是图片或图片集，典型包括：

- B-scan 图像；
- S-scan 图像；
- TFM/PAUT 成像截图；
- 设备导出的伪彩图或报告截图；
- 人工裁剪后的检测图。

如果输入只是渲染图片，系统通常无法自动知道：

- 探头型号、频率、阵元数量、楔块；
- 声速、折射角、聚焦法则；
- 扫查路径、编码器位置、起点和方向；
- 灵敏度、DAC/TCG、增益、闸门；
- 试块校准和验收等级。

因此，报告中应把模型识别结果定位为“图像辅助识别结果”，不能直接等同于标准意义上的超声检测结论。

## 二、B 扫图像中常见可疑特征

Agent 可把以下内容作为复核提示，但不能单独据此判废：

- 局部高亮、孤立反射点、连续强反射带；
- 与背景噪声明显不同的局部纹理；
- 多张相邻图像中位置稳定或连续移动的反射特征；
- 靠近几何边界、底波、侧壁或坐标轴区域的强响应；
- 与已知缺陷人工标注相似的亮点、亮斑或弧形响应。

需要特别提示：

- 图像底部、边缘、色标、坐标轴、文字、网格线容易被模型误检。
- 小缺陷在整图缩放后可能消失，YOLO 需要足够多同类型标注样本或切片检测策略。
- 置信度很低的框不能作为正式缺陷结论，只能作为人工复核候选。

## 三、0 检出场景处理

如果模型检出缺陷数为 0，Agent 应提示：

- 0 检出不等于无缺陷。
- 应逐张查看原图，重点检查局部高亮、小反射点、连续反射轨迹和人工经验认为异常的区域。
- 可尝试降低模型阈值进行排查，但低阈值结果应作为候选，不直接进入正式结论。
- 对明显缺陷应使用“框选补录”，并在报告中标记来源为“人工”。
- 如果多批同类 B 扫图均 0 检出，应判断为模型与数据域不匹配，需要重新标注并训练。

## 四、坐标与比例尺

当前系统采用图片内坐标：

- 原点：图片左上角；
- X 方向：向右增大；
- Y 方向：向下增大；
- 未标定：只输出像素坐标；
- 手动比例/两点比例尺：只换算图片内毫米坐标，不推断工件全局位置。

Agent 应避免输出“小车位置”“焊缝全局坐标”“工件绝对坐标”等无法由图片本身确定的信息。

## 五、复核流程建议

建议操作人员按以下顺序处理：

1. 上传图片，确认图片预览和数量正确。
2. 如有比例尺，先做两点标定或上传元数据。
3. 点击“开始检测”。
4. 若模型有结果，先复核待复核项，确认或标为误检。
5. 若模型 0 检出或明显漏检，逐张图片框选补录。
6. 生成报告前，确认缺陷来源、坐标标定状态和备注完整。

## 六、报告风险提示

可使用以下提示：

- “本批次存在人工补录缺陷，说明模型可能对该类小目标或当前数据域存在漏检风险。”
- “本批次模型检出为 0，但人工复核发现疑似缺陷，建议补充同类样本并重新训练模型。”
- “缺陷物理尺寸由图片比例尺换算得到，不代表设备原始测量数据。”
- “若用于验收，应结合原始超声数据、检测工艺、标准试块校准记录和适用标准进行复核。”
