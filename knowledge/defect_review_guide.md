# 工业图像缺陷复核参考

本资料用于 Agent 辅助分析，不替代持证检测人员结论。

## 复核原则

- 模型检出为 0 不等于无缺陷，应结合原图、标定比例、设备工况和人工复核记录判断。
- 小目标、低对比度、噪声纹理、图像缩放和训练集差异可能导致漏检。
- 人工补录缺陷应在报告中区分来源，避免把人工判断描述为模型自动识别结果。
- 未完成比例尺标定时，只输出图片内像素坐标，不推断工件全局坐标。

## 报告建议

- 对未标定图片，应说明“缺陷位置为图片内像素坐标，未换算为物理坐标”。
- 对模型低置信度或人工补录缺陷，应建议复检或由持证人员确认。
- 对批量图片，应说明检测图片数量、缺陷数量、人工补录数量和误检处理情况。
