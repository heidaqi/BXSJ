# PAUT-A扫多帧二维缺陷辅助风险评价体系 v1.0

## 定位

本体系用于本项目内的风险排序、复核优先级和报告草稿生成，不替代 GB/T、ISO、ASME 等正式验收标准。
系统不得直接输出“合格、不合格、判废”。“维修评估”和“停用待评估”均表示进入工程评估流程，最终结论应由具备资质的人员依据产品标准、检测工艺、校准记录、材料、载荷和服役条件作出。

## 参考依据边界

- ISO 13588:2019：PAUT 可用于焊缝检测、定位、尺寸估计和表征，但验收等级应由其他标准或合同文件规定。
- ISO 19285:2017：给出 PAUT 焊缝检测验收等级，适用条件和缺陷分类需与检测程序配套确认。
- GB/T 11345-2023：焊缝超声检测技术、检测等级和评定过程应按检测工艺、灵敏度、参考试块和人员资质执行。
- GB/T 29712-2023：焊缝超声检测验收等级涉及缺陷幅度、长度、分组和验收等级，当前软件在缺少完整校准和产品标准时不得直接套用验收阈值。
- ASME BPVC Section V Article 4：PAUT 应记录程序、设备、编码扫描、A扫原始数据、焦律和扫描覆盖等信息；软件分析只能作为检测证据链的一部分。

## 风险等级

| 等级 | 分值范围 | 含义 | 建议 |
|---|---:|---|---|
| 低 | 0-2 | 有异常线索，但证据弱或不稳定 | 继续观察，按计划复检 |
| 中 | 3-5 | 异常较明确，但类型、尺寸或稳定性仍不足 | 人工复核A扫、DAS和检测结果 |
| 高 | 6-8 | 多帧持续、响应较强或形态可疑，可能影响使用安全 | 建议维修评估或补充检测 |
| 严重 | >=9且满足严重门槛 | 平面型强异常，多帧稳定，尺寸占比较大或位于敏感区域 | 建议停用待评估 |

## 评分指标

| 指标 | 条件 | 分值 |
|---|---|---:|
| 多帧持续性 | 仅1帧出现 | 0 |
| 多帧持续性 | 2帧出现 | +1 |
| 多帧持续性 | >=3帧出现 | +2 |
| A扫响应强度 | 中位评分 >=0.60 | +1 |
| A扫响应强度 | 中位评分 >=0.85 | +2 |
| 通道支撑 | 支撑通道 >=4 | +1 |
| 通道支撑 | 支撑通道 >=8 | +2 |
| 成像边界支持 | 校验后结果含有效二维边界 | +1 |
| 成像边界支持 | 多项定量结果通过质量门控 | +2 |
| 形态危险性 | 点状/近圆形，偏气孔 | +0或+1 |
| 形态危险性 | 不规则中等长宽比，偏夹渣/夹杂 | +1 |
| 形态危险性 | 长宽比 >=3，偏裂纹/未熔合 | +2 |
| 尺寸占板厚比例 | 二维长度或A扫响应范围 >=0.10t | +1 |
| 尺寸占板厚比例 | 二维长度或A扫响应范围 >=0.25t | +2 |
| 深度位置 | 靠近表面/底面10%厚度范围 | +1 |
| 工程敏感区域 | 元数据标记为焊缝根部、坡口、受力区、压力边界 | +2 |
| 多缺陷组合 | 同批次存在多个分离候选 | +1 |

## 严重等级门槛

只有同时满足以下条件时，才允许输出“严重”：

1. 疑似裂纹、未熔合、未焊透等平面型缺陷；
2. 至少3帧支持；
3. A扫响应强或通道支撑强；
4. 二维长度占板厚 >=25%，或靠近表面/底面/关键受力区域。

否则即使总分达到9分，也最高输出“高”。

## 缺陷类型推理规则

| 类型 | 主要证据 | 可能成因 | 风险解释 |
|---|---|---|---|
| 裂纹/线状平面型缺陷 | 长宽比>=3，多帧连续，A扫响应范围较长，通道支撑强 | 焊接残余应力、热影响区脆化、疲劳载荷或既有缺陷扩展 | 可能疲劳扩展，降低承载能力，焊缝失效风险较高 |
| 未熔合/未焊透 | 线状/平面型，靠近坡口、根部、层间区域，深度位置符合焊接界面 | 热输入不足、坡口清理差、焊接角度不良 | 有效承载截面降低，缺口效应明显 |
| 气孔/点状孔洞 | 近圆形/椭圆形，长宽比较小，孤立或成簇点状响应 | 气体逸出不足、保护气问题、湿度或污染物 | 单个小孔风险较低，聚集孔可能造成应力集中或泄漏风险 |
| 夹渣/夹杂 | 不规则形态，中等长宽比，可能沿焊道方向分布 | 层间清理不足、熔渣卷入、夹杂污染 | 可能形成局部应力集中，连续夹渣会削弱承载截面 |
| 未分类异常 | 定量结果缺失、通道支撑弱或质量门控未通过 | 可能是真缺陷，也可能是噪声、边界或旁瓣 | 必须复核原始A扫和相邻通道，不能定性 |

## 输出边界

Agent 输出必须使用条件性措辞，例如“疑似”“可能”“建议复核”“建议维修评估”。不得把风险等级写成正式验收等级，不得把二维截面长度写成三维真实长度，不得在缺少校准和适用标准时给出合格性结论。
