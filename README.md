# 超声缺陷智能检测系统（BXSJ）

BXSJ 是面向超声相控阵检测实验的本地桌面软件。系统接收 A扫/FMC 数据，调用 MATLAB 算法完成 DAS 成像、缺陷识别、定位和二维定量，再对校验后的算法结果进行人工复核、风险解释和 PDF 报告归档。

当前项目以团队 MATLAB 算法输出为唯一检测与定量依据。Agent 不重新计算缺陷类别、位置或尺寸，只负责证据完整性检查、风险说明、复核建议和报告文字审查。

## 主要功能

- 递归发现并校验 16发16收 FMC 数据组。
- 调用 `algorithms/matlab/Paut.m` 和相关算法完成成像与检测。
- 实时展示成像、缺陷类别、位置、尺寸、方向、峰值和质量提示。
- 将采集数据、校验后结果、扫查时间、人工复核和坐标标定按帧绑定。
- 使用 LangGraph 编排证据检查、风险评价、Agent 解释和报告准备。
- 生成面向检测人员的 PDF 报告和结构化明细。

## 系统结构

```text
FMC 数据源
  -> 数据发现与格式校验
  -> MATLAB 成像和检测
  -> 校验后结果适配
  -> 帧记录与批次归档
  -> 人工复核
  -> Agent 辅助分析
  -> PDF 报告
```

检测、Agent 和报告共享同一份校验后结果。缺失字段保持缺失，不使用预校验候选或大模型内容补造检测数值。

```powershell
.\setup_desktop_dev.ps1

以后运行开发版：

桌面端使用 PySide6 QtWebEngine，启动时自动运行仅监听本机的 FastAPI 服务并加载 React 前端。需要分别调试前后端时可运行：

```

## MATLAB

源码开发版优先使用本机 MATLAB Engine 或 `matlab.exe`。MATLAB 不可用时桌面程序仍可启动，但 PAUT 成像与检测不可用，历史记录、设置和已有报告仍可查看。

系统不会修改 MATLAB 安装。可在应用设置中填写 MATLAB 根目录或可执行文件路径，并使用环境自检确认状态。

## 数据输入

当前主流程处理 16发16收 FMC 数据，并支持从父目录递归发现多个有效数据组。校验器可识别以下形式：

1. 16 个数字命名的 TXT 文件，每个文件包含发射位置、时间和 16 个接收通道。
2. `tx_1` 至 `tx_16` 目录，每个目录包含 16 个接收通道文件。
3. 单个宽表文件，第一列为时间，后续 256 列按发射/接收通道排列。

每组会检查通道数量、采样点、时间轴、NaN/Inf 和阵元配置。一个父目录中部分数据无效时，有效组仍可继续处理，无效组会显示跳过原因。

当前算法支持团队定义的两套 16 阵元配置。存在明确阵元信息时使用数据中的配置；缺少阵元信息时使用当前默认配置，并在结果中记录配置来源。阵元位置会参与成像、定位和定量，不能通过文件夹名称猜测。

## 使用流程

1. 打开“实时监控”，选择单个数据组或包含多个数据组的父目录。
2. 点击“校验数据源”，确认发现、通过和跳过数量。
3. 设置采样率、模拟扫查间隔或车速等本次参数。
4. 点击“开始处理”，系统在后台逐组调用 MATLAB，前端异步显示最新结果。
5. 处理完成后点击“停止处理”，当前会话归档为历史批次。
6. 在批次复盘中检查图像和结果，必要时修改复核状态或补充记录。
7. 在“Agent 与报告”页面启动辅助分析，并由用户选择报告保存位置。

切换新数据源会新建会话。旧会话只作为历史批次保留，不会继续向当前分析或报告提供数据。

## 统一结果口径

每个数据组使用唯一 `frame_id` 绑定：

- 原始数据引用和数据指纹；
- 扫查时间、帧序号和会话信息；
- DAS 图像与数值结果；
- 校验后的缺陷类别、位置、峰值、尺寸和方向；
- 质量状态及算法提示；
- 坐标标定和人工复核修改。

人工复核修改会写回统一帧记录，后续 Agent 与重新生成的报告读取最新版本。未标定时只使用算法已经给出的物理坐标，不利用图片像素比例补造工件全局坐标。

## Agent

Agent 是辅助分析工具，不替代持证检测人员或适用验收标准。它只读取校验后的检测结果及质量状态，不修改缺陷类别、坐标、尺寸、方向和峰值。可信程度、辅助风险等级和处置建议分别评价；质量不足时明确提示补充检测，不输出确定性合格结论。

大模型不可用时，系统仍可生成确定性本地摘要和基础报告。API Key 可在应用设置中填写，保存在运行目录的 `config/secrets.env`，该目录已被 Git 忽略。

## 报告

PDF 报告包含检测范围、引用文件、术语、测试条件、标定信息、测试方法、检测结果、典型图像、风险结论和复核说明。报告只使用当前批次的最新校验结果与复核记录；未提供的信息不会自动编造。

报告由用户主动生成，并可自行选择保存目录。辅助风险等级不等同于产品标准验收等级，也不构成自动判废。

## 配置与隐私

复制 `.env.example` 为 `.env` 可设置开发环境；桌面端也可直接在应用内配置。推荐使用相对路径，便于项目复制到其他电脑。

公共仓库不包含 `.env`、API Key、原始或测试数据、用户数据库、日志、检测结果、报告、虚拟环境、构建缓存、EXE、MATLAB Runtime 和安装包。项目运行所需算法模型保存在 `models/`；训练数据和训练过程产物不属于运行时依赖。
